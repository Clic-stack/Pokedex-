# Contributing to Pokédex 🎮

First of all, thank you for considering contributing to this project! It's people like you who make the open-source community such an amazing place to learn and create.

## 🚀 How Can I Contribute?

### Reporting Bugs 🐛
If you find any UI glitches or logical errors (e.g., Pokémon not loading, pagination errors, or protected routes failing), please create an issue in the repository including:
* A clear and descriptive title.
* * Description of the bug and steps to reproduce it.
* Mention your browser and if the trainer name was set in the global state.

### Suggesting Enhancements 💡
Do you have an idea to optimize the Pokémon search or add new visual features to the details view?
* Create an **Issue** explaining the enhancement.
* If you plan to implement it, please wait for discussion before sending a Pull Request.
  
### Pull Requests 🏗️
1. Fork the repository.
2. Create your feature branch (`git checkout -b feature/AmazingFeature`).
3. Since this project uses **Vite** and **TypeScript**, make sure there are no linting or type errors before committing.
4. Commit your changes using **Conventional Commits** (e.g., `feat: add social login`).
5. Push to the branch (`git push origin feature/AmazingFeature`).

## ⚖️ Style Guide
* Always define interfaces or types for API responses and component props.
* Use `useContext` and `useReducer` for global data (like the trainer name).
* Maintain the `ProtectedRoute` logic for the Pokédex access.
* Keep the README updated if you add new features or components.

# Contribuyendo a: Pokédex 🎮

En primer lugar, ¡gracias por considerar contribuir a este proyecto! Son personas como tú las que hacen de la comunidad de código abierto un lugar increíble para aprender y crear.

---

## 🚀 ¿Cómo puedo contribuir?

### Reportar Errores (Bugs) 🐛
Si encuentras fallos en la interfaz o errores lógicos (ej: los Pokémon no cargan, errores en la paginación o fallos en las rutas protegidas), por favor crea un "Issue" en el repositorio incluyendo:
* Un título claro y descriptivo.
* Descripción del error y pasos para reproducirlo.
* Menciona tu navegador y si el nombre del entrenador estaba configurado en el estado global.

### Sugerir Mejoras 💡
¿Tienes una idea para optimizar la búsqueda de Pokémon o añadir nuevas funciones visuales a la vista de detalles?
* Crea un **Issue** explicando la mejora.
* Si planeas implementarla, por favor espera a que se discuta en el Issue antes de enviar un Pull Request.

### Pull Requests 🏗️
1. Haz un **Fork** del repositorio.
2. Crea tu rama de mejora (`git checkout -b feature/IncreibleMejora`).
3. Como este proyecto usa **Vite** y **TypeScript**, asegúrate de que no haya errores de tipado o de linter antes de hacer el commit.
4. Realiza tus **Commits** usando **Conventional Commits** (ej: `feat: add social login`).
5. Haz **Push** a tu rama (`git push origin feature/IncreibleMejora`).

## ⚖️ Guía de Estilo
* Define siempre interfaces o tipos para las respuestas de la API y las props de los componentes.
* Usa `useContext` y `useReducer` para datos globales (como el nombre del entrenador).
* Mantén la lógica de `ProtectedRoute` para el acceso a la Pokédex.
* Mantén el README actualizado si añades nuevas funcionalidades o componentes.
